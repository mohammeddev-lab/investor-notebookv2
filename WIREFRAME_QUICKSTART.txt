This is a wireframe-based implementation of the Investment Notebook app.

WHAT'S INCLUDED
═══════════════════════════════════════════════════════════════════════════════

✅ Landing Page        - Two buttons: جديد, القديم
✅ New Page            - Type selection with preview boxes
✅ Details Page        - Form entry with image preview
✅ Old Page            - List of saved records
✅ Database            - SQLite auto-initialization
✅ API Routes          - CRUD operations
✅ RTL Arabic Support  - Full right-to-left layout

QUICK START (3 STEPS)
═══════════════════════════════════════════════════════════════════════════════

Step 1: Install Dependencies
────────────────────────────
  cd d:\investor-notebook
  npm install

Step 2: Build the UI
────────────────────────────
  node build-wireframe-ui.js

Step 3: Start Development Server
────────────────────────────
  npm run dev

Then open: http://localhost:3000

  docker build -t notebook .
  docker run -p 3000:3000 notebook

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

"Module not found" error:
  → npm install
  → Delete node_modules and .next
  → npm install again

"Port 3000 in use" error:
  → npm run dev -- -p 3001
  → Use different port

"Database locked" error:
  → Delete data/notebook.db
  → Restart npm run dev

"Text not RTL" issue:
  → Check HTML has dir="rtl"
  → Check CSS has direction: rtl
