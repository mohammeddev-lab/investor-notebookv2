💾 DATABASE STRUCTURE
═══════════════════════════════════════════════════════════════════════════════

TYPES TABLE:
  id (Primary Key)
  name (Required, Text)
  description (Text)
  image_url (Text)
  last_opened_at (DateTime)
  last_edited_at (DateTime)
  created_at (DateTime, Auto)
  updated_at (DateTime, Auto)

RECORDS TABLE:
  id (Primary Key)
  type_id (Foreign Key → types.id, Cascade Delete)
  title (Required, Text)
  description (Text)
  amount (Number)
  problem (Text)
  suggested_solution (Text)
  status (active/inactive/completed)
  priority (low/medium/high)
  date (DateTime)
  notes (Text)
  created_at (DateTime, Auto)
  updated_at (DateTime, Auto)

🔌 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

TYPES API:
  GET    /api/types                  List all types
  POST   /api/types                  Create new type
  GET    /api/types/[id]             Get type details
  PUT    /api/types/[id]             Update type
  DELETE /api/types/[id]             Delete type

RECORDS API:
  GET    /api/records                List all records
  GET    /api/records?typeId=...     Filter by type
  GET    /api/records?status=...     Filter by status
  GET    /api/records?search=...     Full-text search
  POST   /api/records                Create new record
  GET    /api/records/[id]           Get record details
  PUT    /api/records/[id]           Update record
  DELETE /api/records/[id]           Delete record
