TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

"Command not found: node build-app.js"
→ Make sure you're in d:\investor-notebook directory

"Module not found"
→ Run: npm install
→ Then: node build-app.js

"Port 3000 already in use"
→ Run: npm run dev -- -p 3001

"Database locked"
→ Delete: data/notebook.db
→ Run: npm run dev

"Build fails"
→ Delete: node_modules and .next
→ Run: npm install
→ Run: node build-app.js
→ Run: npm run dev
