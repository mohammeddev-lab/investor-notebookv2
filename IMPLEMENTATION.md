🔌 API ENDPOINTS CREATED
═══════════════════════════════════════════════════════════════════════════════

INVESTMENT TYPES API:
  GET    /api/types
         → Returns: { success: true, data: [...types] }
  
  POST   /api/types
         Body: { name, description, image_url }
         → Returns: { success: true, data: {...type} }
  
  GET    /api/types/[id]
         → Returns: { success: true, data: {...type} }
         → Updates: last_opened_at timestamp
  
  PUT    /api/types/[id]
         Body: { name, description, image_url }
         → Returns: { success: true, data: {...type} }
         → Updates: last_edited_at timestamp
  
  DELETE /api/types/[id]
         → Returns: { success: true, message: "Type deleted" }
         → Cascades: Deletes all associated records

INVESTMENT RECORDS API:
  GET    /api/records
         Query params: typeId, status, search
         → Returns: { success: true, data: [...records] }
  
  POST   /api/records
         Body: { type_id, title, description, amount, problem, 
                 suggested_solution, status, priority, date, notes }
         → Returns: { success: true, data: {...record} }
  
  GET    /api/records/[id]
         → Returns: { success: true, data: {...record} }
  
  PUT    /api/records/[id]
         Body: { all fields }
         → Returns: { success: true, data: {...record} }
  
  DELETE /api/records/[id]
         → Returns: { success: true, message: "Record deleted" }

EXAMPLE QUERIES:
  GET /api/records?typeId=type-1
  GET /api/records?status=active
  GET /api/records?search=investment
  GET /api/records?typeId=type-1&status=active&search=property
