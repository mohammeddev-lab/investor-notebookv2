# Investor Notebook - Editable Cards

نسخة بسيطة ومحسنة من مذكرة المستثمر.

## الجديد في هذه النسخة
- 10 كروت أنواع تظهر في سطر واحد.
- يمكن التحريك يمين ويسار بين الكروت.
- عند الضغط على الكارد في صفحة New يمكن تعديل اسمه ووصفه.
- يمكن إضافة صورة لكل كارد من الجهاز.
- الصور والأسماء تحفظ داخل المتصفح باستخدام localStorage.
- لا توجد قاعدة بيانات ولا مكتبات Native.

## التشغيل

```bash
npm install
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```
