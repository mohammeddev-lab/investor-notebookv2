API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════

TYPES (5 endpoints):
  GET    /api/types              List all investment types
  POST   /api/types              Create new type
  GET    /api/types/[id]         Get type details
  PUT    /api/types/[id]         Update type
  DELETE /api/types/[id]         Delete type

RECORDS (5 endpoints):
  GET    /api/records            List all records (with filters)
  POST   /api/records            Create new record
  GET    /api/records/[id]       Get record details
  PUT    /api/records/[id]       Update record
  DELETE /api/records/[id]       Delete record

Query Parameters:
  ?typeId=...    Filter by type
  ?status=...    Filter by status
  ?search=...    Full-text search


DATABASE
═════════════════════════════════════════════════════════════════════════════

Types Table:
  - id (Primary Key)
  - name (Required)
  - description
  - image_url
  - last_opened_at
  - last_edited_at
  - created_at, updated_at

Records Table:
  - id (Primary Key)
  - type_id (Foreign Key, CASCADE DELETE)
  - title (Required)
  - description
  - amount
  - problem
  - suggested_solution
  - status (active/inactive/completed)
  - priority (low/medium/high)
  - date
  - notes
  - created_at, updated_at

Auto-Seeded Data:
  - 3 investment types (Real Estate, Stocks, Business)
